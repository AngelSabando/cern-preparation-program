# CERN Preparation Program

## Nombre del programa
CERN Open Data Preparation Program

## Objetivo personal
Familiarizarme con el manejo, exploración y análisis de datos, comprendiendo el flujo de trabajo experimental y aplicando buenas prácticas de desarrollo y reproducibilidad científica.

## Tecnologías y áreas a fortalecer
- **Entornos reproducibles:** Gestión de software e imágenes de análisis mediante Docker.
- **Formatos científicos:** Comprensión e inspección de estructuras de datos específicas como CMS NanoAOD.
- **Flujos de trabajo:** Manejo de terminal Unix y control de versiones con Git para proyectos de investigación.
